# @deeptokens/mcp

MCP server that lets Claude Code delegate work to [pi](https://github.com/earendil-works/pi)
workers on OpenAI models, through your ChatGPT subscription.

```bash
npx -y @deeptokens/mcp pi     # /login openai, "Sign in with ChatGPT"
npx -y @deeptokens/mcp init   # asks: user level (every repo) or project level (this repo)
```

Tools, model routing and config:
[github.com/megalath/DeepFuckinTokens](https://github.com/megalath/DeepFuckinTokens#readme).
